# November 2026

Things I'm seeing/reading/watching/listening to in November 2026...

## Posts

* [Scaling Agentic Coding As If People Still Mattered](https://adamtornhill.substack.com/p/scaling-agentic-coding-as-if-people) (Adam Tornhill)
  + The limit on running many agents isn't how many run at once but how many need focused human attention. Constant task-switching erodes decision quality and creativity, so sustainable AI-first workflows have to protect the mental downtime problem-solving depends on.
* [Review gates for code you didn't write](https://smcgowan.me/posts/review-gates-for-code-you-didnt-write/)
  + Replaces line-by-line human review of agent-written code with an automated architect review on every PR. Across 336 reviews, change size predicted blocking findings better than touching sensitive paths - so route human attention by assessed risk and record every skipped review step.
* [How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/)
  + The Claude Code team moved most code reading to automated layers - Claude review, security review, CI and risk-scaled human approval - backed by flags and fast rollback. Between June and September merged PRs more than doubled while the revert rate fell by over 40%.
* [Spotify cut their Claude Code token bill](https://lnkd.in/p/gWg8WKqP) (Aakash Gupta)
  + Spotify cut its Claude Code token bill by ~90% with a hook that blocks full reads of files over 350 lines; a cheaper model reads them and returns only the answer, leaving judgment to the frontier model.
* [Critical thinking when agents do the work](https://lnkd.in/p/gqgMuWnz) (Addy Osmani)
  + Warns of "cognitive surrender" and "comprehension debt" when people stop checking agent output. Form a hypothesis before prompting, define "verified" upfront, and keep ownership of intent and accountability.
* [Thesis: AI's impact on software engineering](https://lnkd.in/p/gwSVFHDk) (Annie Vella)
  + Annie Vella finishes her 171-page Master of Engineering thesis at the University of Auckland, arguing engineers' roles are shifting toward "supervisory engineering work" - and that the shift should be designed deliberately.

## Other

* [Spring AI Recipes](https://www.habuma.com/springairecipes/) (Craig Walls)
  + A collection of Spring AI recipes for Java/Spring developers building AI apps and agents - RAG, MCP servers, agents, chat memory, guardrails and voice.
* [Building a Coding Agent From Scratch](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course)
  + A free, open-source course on harness engineering, building a Python coding agent from a bare agent loop up to remote cloud agents. "The agent is ~20 lines. The course is everything else, known as the harness."
* [ECC](https://github.com/affaan-m/ECC)
  + An MIT-licensed toolkit adding structured engineering workflows to Claude Code, Codex and Cursor - specialised agents, skills, hooks, memory and a security scanner.
* [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)
  + A lightweight spec for commit messages (`feat:`, `fix:`, `BREAKING CHANGE`) that maps onto SemVer and makes changelogs and release tooling automatable.
* [TokenEconomizer](https://github.com/microsoft/TokenEconomizer) (Microsoft)
  + Black-box cost control for coding agents like Claude Code and Codex: learns from a repo's earlier sessions to remember repo facts, prune unused tools and break failure loops. On SWE-Bench, mean cost fell 18-31% with success up in four of five agent-model combinations.
* [Harness²](https://github.com/google-research/harness2) (Google Research)
  + Recursive agent harnessing: refines the prompts, tools, memory and orchestration around a fixed model per task via a propose/probe/compose loop, carrying lessons across tasks. Reports gains of up to 11.5 points on WorkBuddy-Bench.
* [WorkBuddy Bench](https://github.com/Tencent/workbuddy-bench) (Tencent)
  + A benchmark for coding agents on realistic dev, PM, QA, ops and security tasks across Code, Web, Office and Security subsets, running agent CLIs in Docker sandboxes and scoring against test suites.
* [r/ClaudeAI post](https://www.reddit.com/r/ClaudeAI/s/vqkphYvsVB) (r/ClaudeAI)
  + Reddit - What's the one prompt you keep coming back to?
